# Reference output

These are the DOT/SCXML files SealFSM **should** produce for `examples/traffic`
and `examples/door`. They were generated by running the bundled IR through the
real `DotSerializer`/`ScxmlSerializer`. After you `mvn package` and run the tool,
diff your `out/` against these to confirm the Spoon-dependent layer behaves on
your Spoon version:

    java -jar target/sealfsm.jar --src examples/door --out out
    diff out/Door.scxml sample-output/Door.scxml
